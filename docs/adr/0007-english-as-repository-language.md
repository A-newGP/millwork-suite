# 0007 — English as the repository language

- **Status:** accepted
- **Date:** 2026-10-25
- **Deciders:** Andrés (@A-newGP)

## Context and problem statement

The founder works in Spanish, but contributors and users of millwork
software are international. Which language do code, issues and documentation
use?

## Considered options

- English
- Spanish
- Bilingual for everything

## Decision outcome

Chosen option: **English** for code, identifiers, commit messages, issues
and the main documentation. Spanish is welcome in Discussions. Translating
the documentation (Spanish first) is a goal. The founder's internal working
documents live in `docs/es/`.

The application itself will be translatable from the start (the core
includes internationalization, per the project plan).

### Consequences

- Good, because the largest possible pool of contributors can participate.
- Bad, because Spanish-speaking shop owners, a key early audience, face a
  barrier until translations exist.
